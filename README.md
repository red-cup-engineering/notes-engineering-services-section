Notes Engineering supplies the dated research-note form beneath an admitted
actuator node. [Markdown Note Engine](https://github.com/red-cup-engineering/markdown-engineering-services-section/tree/main/services/markdown-note-engineering-services-section/apps/markdown-note-engine)
catalogs existing notes and deposits supplied Markdown with its source attribution.

Notes use the article path
`content/text/documents/articles/notes/YYYY/MM/DD/YYYY-MM-DD-note-on-<topic>.md`.
Their directory path carries the restriction from file through data, content,
text, document and article to note.

A deposited note remains research material. Its receipt records the stored
resource; publication, subsequent actuation and engineering acceptance require
their own authority and evidence. Existing notes at legacy paths remain in
place until their owners reconcile them.
